🏏 DS_Cricbuzz LiveStats: Real-Time Cricket Insights

DS_Cricbuzz LiveStats is a real-time cricket analytics project that delivers live match updates, ball-by-ball commentary, and player stats with an interactive dashboard. Designed for cricket enthusiasts, analysts, and developers, it combines data engineering and visualization for a complete sports analytics experience.

🚀 Features

Live scores & ball-by-ball updates

Toss, innings, and commentary tracking

Player performance insights

MySQL integration for structured storage

Streamlit dashboard with dark/light theme support

🛠 Tech Stack

Python – Data fetching & processing

MySQL – Structured match data storage

Streamlit – Interactive dashboard & visualization

Pandas – Data wrangling and analysis
